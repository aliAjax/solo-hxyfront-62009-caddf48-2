# hxyfront-62009 地毯修复档案工作台

给手工地毯修复工作室使用的纹样与修复档案工作台，在原档案页基础上扩展，覆盖档案管理、纹样标注、材料预留、工序推进、冲突追踪与备份导出。

## 功能

- **档案管理**：新增、复制（区域与需求 id 重新映射，工序/快照重置）、删除、按编号/名称/材质/染色搜索、按产地筛选；多档案并存。
- **纹样图标注**：在纹样图（上传图片或内置示例纹样）上框选绘制破损区域，可拖动移动、四角手柄调整尺寸；记录破损类型、严重度与面积占比（矩形自动计算，可手动覆盖）。
- **材料色卡**：色卡多选批量生成补线需求、单个分配；全场需求实时预留库存，展示余量/超预留；RGB 色差超阈值（60）或库存不足时标记冲突并阻止归档。
- **修复工序**：除尘清洗 → 测绘建档 → 染线对色 → 补线修复 → 定型 → 验收，严格按依赖推进，未完成前序不能勾选，染线对色要求材料全部选取、补线要求全部备齐；取消前序级联取消后续。
- **版本快照**：任意时刻创建带备注快照；恢复旧版本前自动备份当前状态（列表中已有内容相同的快照时复用，不重复堆积），历史记录始终保留。
  - 快照数据始终**拍平**：`snapshot.data.snapshots` 恒为空数组，快照不内嵌快照树，连续恢复不会指数膨胀导致页面卡死；旧版嵌套数据在刷新/导入时自动拍平迁移。
- **冲突面板**：实时汇总缺图、区域重叠、材料不足（未选取/色差/缺货）、工序倒置四类问题，支持全场/当前档案范围切换，点击「定位」跳转分区并闪烁来源。
- **整场数据**：撤销 / 重做（Ctrl+Z / Ctrl+Shift+Z）、手动保存、自动防抖持久化到 localStorage（刷新保持进度）、导出 / 导入 JSON 备份。
- **响应式**：窄屏下档案库收起为抽屉，标签分区、表单与画布均可完成核心操作。

## 技术栈

React 19 + Vite + TypeScript（无额外运行时依赖），状态用 useReducer + 历史栈自管理。


## 构建与验收

```bash
npm run build      # 生产构建
npm run typecheck  # 严格类型检查
npm run accept     # 27 项业务规则验收（多档案/多区域/库存冲突/工序门槛/快照/撤销）
npm run e2e        # Playwright 真实浏览器 E2E：桌面 1440 与 390px 窄屏
```

E2E 自动启停 vite dev server，覆盖：连续恢复多版本不卡死、快照列表不重复嵌套、localStorage 刷新持久与旧嵌套数据迁移、恢复后继续编辑/撤销/重做/再建快照、窄屏抽屉选档、触屏拖框绘制破损区域、冲突定位、无横向溢出。容器内首次运行浏览器可能缺系统库，可用 `npx playwright install-deps chromium`（需 root）或设置 `CHROMIUM_LIBS` 指向用户目录依赖。

快照卡死回归重点：
- 不变量测试断言每个 `snapshot.data.snapshots` 为空、连续恢复 5 次每次 <100ms 返回且快照数恒定；
- 真实浏览器在桌面与 390px 下连续恢复，墙钟 <3s、无 `pageerror`。
